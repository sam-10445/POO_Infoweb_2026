PROJETO COM ATIVIDADE 11

Sistema de Agendamento + Tarefa 11 - Filtragem e Ordenação.

Como executar:
1. Abra o terminal dentro desta pasta.
2. Instale as dependências: pip install -r requirements.txt
3. Execute: streamlit run index.py

A pasta e os arquivos JSON ficam juntos. Não e necessario manter a pasta Prova ou o projeto antigo.

Atividade 11 implementada:
- Registrar Atendimento pelo profissional.
- Atendimento possui data, queixa principal, historico de saude, avaliacao, prescricao, horario, total e pago.
- Atendimento pode ter varios servicos realizados, com quantidade e subtotal.
- Total e calculado a partir dos servicos realizados.
- Cliente pode visualizar os atendimentos pendentes e efetuar o pagamento.
- Listagens de horarios e atendimentos sao filtradas e ordenadas.
