# EXERCÍCIO 01 — NOVO CADASTRO

Crie no sistema um cadastro de profissionais.

A classe Profissional deve possuir:

- id
- nome
- email
- fone

Implemente:

1. Classe Profissional
2. ProfissionalDAO
3. métodos necessários no Service
4. ManterProfissionalUI
5. opção Profissionais no IndexUI

O cadastro deve permitir:

- listar
- inserir
- atualizar
- excluir
