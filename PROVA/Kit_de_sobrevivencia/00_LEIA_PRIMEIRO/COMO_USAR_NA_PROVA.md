# COMO USAR NA PROVA

## 1. Leia o enunciado

Descubra primeiro o que o professor está pedindo.

Procure palavras como:

- criar classe
- criar cadastro
- inserir
- listar
- atualizar
- excluir
- adicionar atributo
- associação
- relacionar classes
- alterar Horario
- alterar Service
- criar página
- adicionar ao menu

---

## 2. Encontre o padrão correspondente

### Criar uma nova classe
→ `01_MODELOS_BASE/MODELO_CLASSE.py`

### Criar um cadastro completo
→ `02_CADASTRO/CADASTRO_COMPLETO.md`

### Fazer associação entre classes
→ `03_ASSOCIACOES/ASSOCIACAO_EXPLICADA.md`

### Adicionar atributo
→ `04_ALTERAR_ATRIBUTOS/ADICIONAR_ATRIBUTO.md`

### Alterar Service
→ `05_SERVICE/METODOS_SERVICE.md`

### Alterar interface
→ `06_UI/STREAMLIT_CRUD.md`

### Procurar exercício parecido
→ `07_EXERCICIOS_PROVAVEIS/`

### Precisar de código rapidamente
→ `08_CODIGO_PRONTO/`

---

## 3. Faça as alterações no Projeto

O projeto que deve ser alterado na prova é:

`Projeto/`

Não altere o material desta pasta para resolver a prova.

---

## 4. Depois de implementar

Use:

`CHECKLIST_FINAL.md`

para conferir se não esqueceu nenhuma parte.

---

# REGRA PRINCIPAL

Não tente escrever tudo do zero.

Procure no KIT_PROVA_POO o código mais parecido com o que o professor pediu.

Depois:

1. copie;
2. renomeie;
3. altere os atributos;
4. altere os nomes dos métodos;
5. conecte ao Service;
6. conecte à UI;
7. teste.
